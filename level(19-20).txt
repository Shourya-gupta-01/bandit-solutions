Bandit Level-19  
  
To connect to ssh run command:  
ssh -p 2220 bandit19@bandit.labs.overthewire.org  
  
Level(19-20) commands in sequence:  
Description of the problem -> To gain access to the next level, you should use the setuid binary in the homedirectory. Execute it without arguments to find out how to use it. The password for this level can be found in the usual place (/etc/bandit_pass), after you have used the setuid binary.
  
Commands in sequence:  
1. ./bandit20-do cat /etc/bandit_pass/bandit20 
  
Use the password to enter level 20.
